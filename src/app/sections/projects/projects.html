Generador QR

Aplicación web full-stack que permite generar códigos QR a partir de URLs con un sistema de enlaces temporales y expiración controlada desde el servidor. Implementa un backend en Node.js con Express para la gestión de rutas dinámicas, validación de URLs y redirección segura. El proyecto incluye generación de códigos QR, sistema de enlaces compartibles y despliegue en producción mediante Render, demostrando habilidades en desarrollo backend, manejo de APIs HTTP y despliegue de aplicaciones web.
